# Heroes of History

Guides for Heroes of History Allied Culture events.

- **Maya Empire: Gold (Top 1%) F2P Guide** (`index.html`): a step-by-step viewer based on TazzDevilTV's video, ["ALL YOU NEED TO KNOW to Hit Gold (1%) in MAYA AC"](https://www.youtube.com/watch?v=5eOxE69uYAI).

## Deploying on Vercel

This is a static site with no build step.

1. In Vercel, choose **Add New → Project** and import `sharpcoder28/Heroes-of-History`.
2. Leave **Framework Preset** as **Other**. Leave the build command and output directory empty.
3. Click **Deploy**. Every push to `master` redeploys the site.

To preview locally, open `index.html` in a browser.
